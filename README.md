## Morpheus Plugin SDK

[Morpheus Share Website](https://share.morpheusdata.com/plugin) - Published plugins for various integrations, both officially supported and third party. In the majority of cases, the code of each plugin can be access from this website so serve as good examples. 

[Morpheus Developer Zone Website](https://developer.morpheusdata.com/) - Documentation for several commonly used plugin providers, but out of date. Good place to start but look to the package class reference for currently available providers.

[Plugin SDK Class Reference](https://developer.morpheusdata.com/api/index.html?overview-summary.html) - Searchable reference for the SDK and exposed providers.

[Morpheus Report Generator](https://olliehpe.github.io/morpheus-report-generator/) - Create simple reports for Morpheus using a nocode approach.

### Plugin Examples
Several publicly available example plugins to serve as a starting point. Note some examples are not maintained, and are for reference not production use.

[Spoonboy Report Pack](https://github.com/olliehpe/spoon-boy-report-pack) - Several custom reports for appliance user administration.

[Socket Usage Report](https://github.com/olliehpe/socket-usage-report) - A recent socket count report for private and public clouds. Guide only.

[Custom Tab Plugin](https://github.com/olliehpe/custom-tab-plugin) - A custom tab example with some CRUD components to provide an updatable interface in the UI.

[Morpheus Example Reports Plugin](https://github.com/martezr/morpheus-example-reports-plugin) - Misc examples.

[Morpheus Plugin Samples](https://github.com/HewlettPackard/morpheus-plugin-samples) - Misc examples of several different plugin providers.
